## 🚀 Flagship Systems

### 1. [NexusIQ — Autonomous Campus Intelligence & University RAG](https://agenticrag-nine.vercel.app/)
- **Category:** Multi-Agent AI / Hybrid Vector Search / Enterprise Full Stack
- **Architecture:** LangGraph multi-agent cyclic router, Qdrant hybrid vector DB (Dense + BM25 sparse search), PostgreSQL ground-truth ledgers, FastAPI ingestion workers, Next.js 16 interactive cockpits.
- **Production Provenance:** Deployed live at ALITS serving 3,500+ students and 180+ faculty across 9 engineering departments with 100% cited source provenance.

### 2. [ToolForge — Privacy-First In-Browser Document & Image Suite](https://tools-forge-kappa.vercel.app/)
- **Category:** Client-Side Engineering / WebAssembly / Web APIs
- **Architecture:** 100% in-browser memory buffer manipulation using `pdf-lib` WebAssembly, HTML5 Canvas 2D context, and local worker threads.
- **Security & Efficiency:** Zero cloud egress (files never leave device RAM), zero server compute cost, and instant array-buffer compression.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/sandeep-45436/Sandeep-Kapadam.git

# Navigate to project directory
cd Sandeep-Kapadam

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
